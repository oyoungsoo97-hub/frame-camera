# FRAME 2.1.0 — store preparation beta

Local camera coaching in German, English and Korean. This preparation release fixes Safari 15 parsing, gallery initialization, storage-failure warnings and native background camera cleanup. When storage fails, automatic capture pauses and the unsaved photo opens for export.

The publisher chose Youngsoo Oh (individual), a one-time €2.99 store price and worldwide availability where sales are allowed. No advertising, subscription or in-app purchases are implemented. Store metadata, icons, graphics, privacy drafts, native integration suites and release audit scripts are included.

Read [the test report](../store/reports/TEST-REPORT.md) for actual results and limitations. Physical-device acceptance, developer accounts, public support email, production signing and store review remain pending. Configured minimum OS versions are not device certifications.

Debug APKs are for testing; simulator apps cannot run on an iPhone. Unsigned AAB/archive samples are not store-upload-ready packages. This beta is not an App Store or Google Play release.
