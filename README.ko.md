# FRAME — 나만의 촬영 코치

**[Deutsch](README.md) · [English](README.en.md) · [한국어](README.ko.md)**

FRAME은 한 사람의 위치·구도·포즈를 실시간으로 안내하는 카메라 앱입니다. 영상은 기기에서 분석하며, **독일어·영어·한국어** UI와 안내·오류 메시지·접근성 라벨·음성 안내를 제공합니다.

[웹 앱 열기](https://oyoungsoo97-hub.github.io/frame-camera/) · [네이티브 빌드 다운로드](https://github.com/oyoungsoo97-hub/frame-camera/releases/tag/v2.0.0)

## 제공하는 형식

| 플랫폼 | 파일 | 필요한 환경 |
|---|---|---|
| HTML / 웹 / PWA | `dist/` 전체 | HTTPS 정적 호스팅, Safari 또는 Chrome |
| 애플 iOS | `ios/App/App.xcodeproj` | macOS, Xcode 26 이상, iOS 15.4 이상, 실제 아이폰용 Apple 서명 |
| 안드로이드 | `android/` Gradle 프로젝트 | Android Studio, JDK 21, API 36 SDK; 실행은 API 24 이상 |
| 자동 빌드 결과 | Android 디버그 APK, iOS 시뮬레이터 `.app.zip` | 해당 GitHub Actions 작업이 성공한 뒤 다운로드 |

iOS와 Android는 웹 화면과 모델을 앱 안에 포함하는 Capacitor 네이티브 프로젝트입니다. 외부 웹사이트를 불러오는 방식이 아닙니다. 시뮬레이터 앱은 실제 아이폰에 설치할 수 없습니다. IPA/TestFlight에는 Apple 서명과 개발자 계정 설정이 필요하고, Android 스토어 배포에는 별도 릴리스 서명 키가 필요합니다. 스토어 등록과 서명 정보는 포함하지 않습니다.

## 주요 기능

- 촬영 버튼이 보이는 전체 화면 카메라와 설정 패널
- 목표 윤곽선, 현재 관절, 이동 방향 화살표
- 키와 카메라 거리를 이용한 **cm/m 이동 추정값**
- 여행·카페·전신·앉은 자세: 7가지 포즈와 손·시선 안내
- 밝기·배경 윤곽·수평선 후보를 이용한 구도 제안
- 세 장을 저장하고 눈 상태·선명도·움직임으로 베스트 후보를 고르는 연속 촬영
- 구도가 2초간 맞으면 자동 촬영, 베스트 모드에서는 눈 뜸과 안정성도 확인
- 전면/후면 전환, 격자, 3:4/1:1, 3초/5초 타이머, 사진 불러오기
- 기기 내 갤러리와 내보내기, 네이티브 앱의 OS 공유 메뉴

## 사용 방법

1. Safari 또는 Chrome에서 웹 앱을 여세요. 아이폰은 Safari의 공유 → 홈 화면에 추가로 앱처럼 사용할 수 있습니다.
2. 상단에서 **한국어**를 선택하세요. 촬영 화면에서는 **설정** 안에 언어 선택이 있습니다. 기기 언어를 자동으로 선택하며 직접 바꾼 설정은 저장합니다.
3. **내 카메라로 시작**을 누르고 카메라 접근을 허용하세요. **데모 체험**은 카메라 권한 없이 사용할 수 있습니다.
4. 촬영 상황과 포즈를 선택하고, 화면 기준 화살표와 윤곽선을 따라 움직이세요.
5. **cm / m 설정**에서 키와 현재 카메라 거리를 입력하세요. 머리와 두 발이 보이는 상태에서 똑바로 서고 휴대폰을 수평으로 잡아 보정합니다.
6. 촬영 후 갤러리에서 후보를 비교하고 사진을 저장하거나 공유하세요.

## 개발 및 빌드

Node.js 22 이상이 필요하며, 간단한 웹 서버에는 Python 3를 사용합니다.

```sh
npm ci
npm run build
npm test
npm run check
npm start
```

`index.html`을 파일로 바로 열면 카메라와 모델이 제대로 작동하지 않습니다. 웹 카메라는 HTTPS 또는 개발용 localhost에서 사용하세요.

```sh
npm run build
npx cap sync ios
npm run ios
# Android:
npx cap sync android
npm run android
```

앱 ID는 `io.github.oyoungsoo97hub.framecamera`입니다. iOS는 Xcode에서 본인의 서명 팀을 선택하세요. Android는 `android/`에서 `./gradlew assembleDebug`로 테스트 APK를 만들 수 있습니다. 자세한 빌드와 배포 절차는 [빌드 문서](docs/BUILD-AND-RELEASE.md)에 있습니다.

## 정확도와 개인정보

한 사람의 촬영을 대상으로 합니다. cm/m는 입력값과 영상 기하를 이용한 추정이며 LiDAR·ARKit 깊이 측정값이 아닙니다. 사람·자세·렌즈·줌이 바뀌면 다시 보정하세요. 앉은 자세에는 서 있는 키 기준 보정을 적용하지 않습니다.

시선 안내는 지시문이며 실제 시선 추적이 아닙니다. 벽이나 지붕을 수평선으로 인식할 수 있습니다. 눈·선명도 분석은 불확실하며 외모를 평가하거나 사람을 식별하지 않습니다.

앱은 사진이나 영상을 서버로 전송하지 않습니다. 갤러리는 앱/브라우저 주소별 로컬 저장소에 보관됩니다. 주소가 바뀌면 별도 갤러리가 열리고, 데이터 삭제나 앱 제거 시 사진이 사라질 수 있습니다. 중요한 사진은 내보내세요. OS 백업 및 공유 대상은 기기 설정과 사용자의 선택에 따릅니다.

빌드 성공은 실제 기기에서 카메라가 검증됐다는 뜻이 아닙니다. 배포 전 실제 iPhone과 Android에서 카메라·성능·배터리·공유 기능을 확인해야 합니다.
